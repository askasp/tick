Is this the simplest change that does the job, and does it look like the rest of
this repo?

- something the repo already has, written again
- an abstraction with one caller, a flag with one value, a setting nothing reads
- code left behind: dead branches, commented-out lines, exports nobody imports
- a name that says less than the thing it names
- a pattern this repo does differently three files away

Taste is not a defect. Ask for a change only where a reader would have to work
to follow it; everything smaller is a note, and you still approve.
